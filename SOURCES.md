# Art sources

The prototype reuses the existing project's selected character and prop images from **Kenney Scribble Dungeons 1.0**, released under CC0. The original license is included at `assets/vendor/KENNEY-SCRIBBLE-DUNGEONS-LICENSE.txt`.

Ground, effects, pickups, skill visuals, and procedural props are drawn at runtime with the Canvas API. The supplied reference sheet was used only as visual direction; no pixels or sprites were extracted from it.

`assets/player/survivor.png`, `assets/player/player-walk-v2.png`, `assets/enemies/enemy-atlas-v2.png`, and `assets/props/prop-atlas-v2.png` were newly generated for this prototype with OpenAI image generation. The supplied sheet was used only as a style reference. These are original assets and were not cropped, traced, or extracted from the sheet. The v2 atlases use chroma-key processing solely to turn their generated flat green backgrounds into transparency.
